"temir" is the FEM program for homogeneous elastic materials by KISHIN OKANO.

[Name] 
"temir" means "iron" in uzbek. It is also the name of amir of Timurid Empire.

[Version]
temir_tri3 : The program for tri3 element(marc element type 201).
temir_quad4 : The program for quad4element(marc element type 3).

[specifications]
He only accepts homogeneous elastic materials.
He only accepts point load or fixed displacemenet as boundary conditions.
All boundary conditions have to be used in job.
